Aplikasi Antrian ini dibuat menggunakan Python (Tkinter) dan MySQL sebagai database. 
Aplikasi ini dirancang untuk membantu pengelolaan antrian secara digital dengan tampilan sederhana dan mudah digunakan.

Fitur utama:
- Pengambilan nomor antrian otomatis
- Generate kode antrian (A001, A002, dst)
- Login admin
- Dashboard admin (CRUD data antrian)
- Update status antrian (menunggu, dipanggil, selesai)
- Display antrian real-time (sedang dipanggil & antrian berikutnya)
- Auto refresh data

Teknologi yang digunakan:
- Python (Tkinter)
- MySQL (XAMPP)
- mysql-connector-python

Aplikasi ini cocok digunakan sebagai simulasi sistem antrian seperti di bank, rumah sakit, atau pelayanan publik.
